# FLOW CRM

Деплой: git push → webhook → автообновление сервера

Пересылка событий Авито ассистенту включается переменными `SONYA_HOOK_URL` и `SONYA_HOOK_AUTH`. Если хотя бы одна не задана, CRM работает как раньше. На сервере их пишут в `/root/crm/.env` и перезапускают сервис `crm`. Значения в репозиторий не коммитить.
